# Chiara Luey

Personal site: an interactive 3D Cornell campus plus About, Work, Projects & Research, Press, Service and Jewelry pages. Live at https://chiaraluey.com

- Static site, no build step needed to serve. Edit content in `src/build.py`, then run `python3 src/build.py` to regenerate the pages.
- Local preview: `python3 serve.py 8080`
